# Project OneRoom

A 2D puzzle platformer that subverts player expectations.

15 levels. One room. Every rule is a lie.

## Tech

- Engine: Godot 4.4.1
- Language: GDScript
- Platform: Web (HTML5 export planned)

## Structure

```
scenes/
  player/       - 角色场景
  components/   - 可复用组件（按钮、门、箱子）
  levels/       - 15 个关卡场景
  ui/           - UI 场景
scripts/
  levels/       - 关卡特有逻辑
assets/
  sprites/      - 图片资源
  audio/        - 音效资源
  fonts/        - 字体资源
```

## Development

1. Install Godot 4.4.1
2. Open project folder in Godot
3. Run main scene
